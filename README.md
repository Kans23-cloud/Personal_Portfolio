## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Kans23-cloud/Personal_Portfolio.git
```

Navigate to the project:

```bash
cd Personal_Portfolio
```

Frontend:

```bash
cd client
```

Open:

```text
index.html
```

Backend:

```bash
cd server
npm install
node server.js
```
